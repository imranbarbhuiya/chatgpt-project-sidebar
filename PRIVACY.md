# Privacy Policy

Last updated: September 12, 2026

Project Sidebar for ChatGPT is a browser extension that organizes ChatGPT conversations into collapsible project groups in the ChatGPT web sidebar.

## Data the extension handles

After you explicitly enable project grouping, the extension reads project names, chat titles, project icons and colors, and ChatGPT conversation and project URLs that are already rendered on `chatgpt.com`.

## How the data is used

This information is used only to group conversations by project and remember project lists and collapse preferences in your browser.

## Storage and retention

The data is stored locally in `chrome.storage.local`. It remains on your device until you clear the learned data from the extension popup, remove the extension, or clear the extension's browser storage.

## Data sharing and transmission

The extension does not transmit user data to the developer or any third party. It has no analytics, advertising, tracking, remote servers, or remotely hosted code. The developer cannot access the locally stored data.

## Limited Use

The extension's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single user-facing purpose. It is not sold, used for advertising, used to determine creditworthiness, or made available for human review.

## Permissions

- `storage`: saves extension settings, collapse state, and learned project metadata locally.
- Access to `https://chatgpt.com/*`: reads the rendered sidebar and project pages and inserts the grouped project sidebar.

## Your controls

You can disable grouping, clear learned project data from the popup, or uninstall the extension at any time.

## Contact

For privacy questions, open an issue in the [public GitHub repository](https://github.com/imranbarbhuiya/chatgpt-project-sidebar/issues).

## Changes

Material changes to this policy or the extension's data practices will be disclosed before the updated practices take effect.
