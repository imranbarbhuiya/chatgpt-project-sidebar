# Chrome Web Store listing

## Name

Project Sidebar for ChatGPT

## Summary

Groups ChatGPT conversations by project with collapsible sections and private, local-only storage.

## Description

Bring project organization to ChatGPT on the web.

Project Sidebar for ChatGPT groups project conversations directly in the existing ChatGPT sidebar, making it easier to switch between related chats without opening the Projects page every time.

Features:

- Groups recent conversations under their project names
- Adds collapsible controls for every project and the complete Projects section
- Matches each project's icon and color
- Learns full project chat lists when you visit a project page
- Keeps ordinary conversations in the standard Recents list
- Stores settings and learned project metadata only in your browser
- Includes no analytics, tracking, advertising, or external servers

The extension reads only the project information already rendered on chatgpt.com. It does not use private ChatGPT APIs, access authentication tokens, or transmit your data.

This is an independent, unofficial extension and is not affiliated with, endorsed by, or sponsored by OpenAI. ChatGPT is a trademark of OpenAI.
